# Product Definition

## 概要

Tab Manager Ex は IntelliJ IDEA 系 IDE 向けのプラグインである。
タブ管理という IDE 標準の操作を、2つの入口からまとめて実行できるようにする。
Git ログから選んだコミットの変更ファイルを一括で開く機能と、エディタのタブを一括でピン留めまたは解除する機能を提供する。
レビューや実装の初期作業で往復する手間を減らすことが目的である。

## 背景

IntelliJ IDEA には、タブのピン留めをファイルごとに実施する操作と、コミットごとの変更ファイルを開く操作がある。
対象が複数になると、ファイルごとに操作する手間が発生し、レビューや実装の初期作業を遅らせる。
本プラグインはこの手間を取り除く。

## 機能

### Open Changed Files

- Git ログのビューで 1 つ以上のコミットを右クリックする。
- コンテキストメニューから "Open Changed Files" を選ぶ。
- 選んだコミットで作成、変更、移動されたファイルがすべてエディタで開かれる。
- 削除されたファイルは無視される。

### Pin All Open Files

- エディタのタブ、またはエディタ領域を右クリックする。
- "Pin All Open Files" を選ぶ。
- 開いているすべてのファイルがピン留めされる。

### Remove All Pins

- エディタのタブ、またはエディタ領域を右クリックする。
- "Remove All Pins" を選ぶ。
- すべてのファイルのピン留めが解除される。

## 動作の主体

- プラグインの ID は `com.github.naoyukik.ijtabmanagerex` である。
- JetBrains Marketplace では ID `29355` として公開されている。
- 3 つのアクションはいずれもユーザーが明示的に起動する。
- 自動実行やバックグラウンド処理は存在しない。

## 層の構成

本プラグインは 3 つの層で構成する。

| 層 | 責務 |
| --- | --- |
| `application/` | アプリケーション層のサービス。IDE の操作をまとめる。 |
| `userInterface/` | ユーザーインターフェース層のアクション。操作をサービスの呼び出しに変換する。 |
| `resources/META-INF/plugin.xml` | アクションの登録。 |

依存の向きは `userInterface/` から `application/` の一方向である。
`application/` は `userInterface/` を参照しない。

## 対応環境

- IntelliJ Platform 2024.3 以降のビルドに対応する。`until-build` は指定しない。
- 対象 IDE は IntelliJ IDEA Ultimate を基準とする。
- Git 関連の機能を使うため Git4Idea への依存を持つ。

## 対象外

- ファイルピンの個別操作。既存の IDE 標準機能に任せる。
- タブの並び替え、タブの分割、ワークスペースの操作。
- Git 以外のバージョン管理システムの操作。
- 設定画面と永続化されるユーザー設定の提供。3 つのアクションにオプションはない。
